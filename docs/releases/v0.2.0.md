# LightRemote 0.2.0

1. **原生工作区**：桌面、终端、文件、剪贴板和会话权限分开显示，支持明暗主题与键盘切换，切换后保留草稿和终端内容。
2. **连接与控制**：邀请输入默认隐藏并在提交后清空，连接可取消，未获主机授权的操作不可用，离开桌面工作区会释放远程键鼠输入。
3. **显示器与文件**：按显示器名称和分辨率选择屏幕，文件目录按名称、类型和大小显示，剪贴板编辑器就近提示无效文本。
4. **权限显示修复**：查询显示器不再覆盖会话权限，刷新屏幕后仍能看到主机授予的能力。

项目现位于 `ca-x/lightremote`，原仓库地址会重定向；本次没有更改 TMP 协议或默认权限。
桌面视频仍为实验性 JPEG 流，真实桌面操作与跨系统外观仍需验证；不保证低延迟。
所有主机权限默认关闭，启用 Shell 会授予主机进程所属用户的执行权限。
二进制未签名，macOS 未公证；`SHA256SUMS` 仅用于校验下载完整性，不证明发布者身份。
本版本不会自动部署 Cloudflare 中继。

1. **Native workspaces**: separate desktop, terminal, files, clipboard and session permissions, with light/dark themes, keyboard navigation and retained drafts and terminal contents.
2. **Connection and control**: invitations are masked and cleared on submission, connections can be cancelled, unavailable permissions disable remote actions, and leaving the desktop releases remote input.
3. **Displays and files**: choose a screen by name and resolution, inspect directory entries by name, type and size, and see clipboard validation beside the editor.
4. **Permission display fix**: querying displays no longer replaces session permissions, so refreshing screens preserves the host's reported capabilities.

The project now lives at `ca-x/lightremote`; the previous repository redirects. TMP and default permissions are unchanged.
JPEG desktop streaming remains experimental; physical-desktop behavior and cross-platform appearance still need validation, with no low-latency guarantee.
All host permissions default off; enabling Shell grants execution as the host process user.
Binaries are unsigned and macOS builds are not notarized; `SHA256SUMS` checks download integrity, not publisher identity.
This release does not deploy a live Cloudflare relay.
