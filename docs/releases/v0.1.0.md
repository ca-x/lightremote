# roc-remote 0.1.0

首个以 **roc-remote** 名称发布的版本。项目由 LightRemote 更名，仓库为
`ca-x/roc-remote`，使用项目所有者提供并确认的鹰形 Logo。

- Web 与原生 NSH 控制端统一名称和 Logo，Web 提供 favicon。
- 原生会话工作区包含 Desktop、Terminal、Files、Clipboard、Session；权限默认关闭。
- 提供桌面主机 CLI、headless CLI、NSH 原生控制端、中继和 Web 静态资源。
- 二进制及归档使用 `roc-remote` 前缀；环境变量统一为 `ROC_REMOTE_*`，请更新部署配置。
- 原 `lightremote.*.v1` profiles、WebSocket 子协议、加密握手和测试向量保持不变；
  内部上传暂存文件前缀也保留，避免更名暴露旧暂存文件。
- 本次按项目所有者要求重置公开版本为 `v0.1.0` 并清理旧 Releases/tags；
  源码提交历史保留，旧验证文档仅代表其记录时的历史状态。

**安全与验证边界：** 邀请包含会话密钥，请勿公开。启用 Shell 相当于授权以主机
进程用户身份执行命令。上传限于已打开的共享目录，精确大小、FIN 和原子拒覆盖提交
规则不变。JPEG 桌面流仍属实验性功能；自动化构建与测试不代表真实 OS 桌面验收。
所有二进制未签名，macOS 未公证；本次发布不包含 live Cloudflare 部署。

## Downloads

Five targets: Windows x64, macOS Intel/Apple Silicon, Linux x64/ARM64.

- `roc-remote`: desktop host and CLI.
- `roc-remote-headless`: CLI without capture, input, clipboard or NSH dependencies.
- `roc-remote-native`: native NSH controller.
- `roc-remote-relay`: self-hosted encrypted-traffic relay.
- `roc-remote-web`: compiled static browser client.

The desktop and headless archives both contain a `roc-remote` executable.
Preserve the archive's `branding/` directory beside the Windows native executable
for its window/taskbar icon. These are raw executable archives, not installers or
macOS application bundles. See the included branding README for icon limitations.

Use `SHA256SUMS` to check download integrity; it is not a publisher signature.
TMP remains transport-independent and unchanged. All service permissions default
off, and relays do not terminate application encryption.
