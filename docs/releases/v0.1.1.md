# LightRemote 0.1.1

v0.1.0 的发布检查发现终端小包突发会关闭会话，未创建 Release；此版本修复了接收缓冲和关闭边界。

首个可试用版本，提供 Web 和 NSH 原生客户端，通过一次性邀请连接主机。

1. **远程操作**：查看实验性 JPEG 桌面流、发送键鼠输入、保存截图，并按需读取或写入文本剪贴板。
2. **终端与文件**：使用真实 PTY Shell，在主机共享目录内上传和下载文件，上传与下载均拒绝覆盖已有文件。
3. **自建中继**：可运行 Rust 中继或使用 Docker，也可部署 Cloudflare Workers 与 Durable Objects 中继。
4. **下载选择**：每个平台分别提供桌面主机 CLI、headless CLI、NSH 原生控制端和中继，另有 Web 静态资源包。

所有主机权限默认关闭；启用 Shell 会授予主机进程所属用户的执行权限。
邀请使用随机密钥加密会话，初版没有持久设备身份或前向保密；使用不可信中继时，请从独立可信的 HTTPS 来源加载 Web 客户端。
桌面功能仍需真机验证，当前有序连接不保证低延迟；Cloudflare 中继默认每次会话累计转发上限为 64 MiB。
二进制尚未签名，macOS 尚未公证；SHA256SUMS 用于校验下载完整性。

The v0.1.0 candidate was withheld after release checks found that a burst of terminal input could close the session; this version fixes receive buffering and shutdown boundaries.

First usable release with Web and native NSH controllers connected through a one-time host invitation.

1. **Remote control**: view the experimental JPEG desktop stream, send keyboard and mouse input, save screenshots, and explicitly read or write text clipboard contents.
2. **Terminal and files**: use a real PTY shell and transfer files inside the host share directory, with uploads and downloads refusing to overwrite existing files.
3. **Self-hosted relay**: run the Rust relay directly or in Docker, or deploy the Cloudflare Workers and Durable Objects relay.
4. **Downloads**: choose separate desktop host CLI, headless CLI, native NSH controller and relay archives for each platform, or the compiled Web client archive.

All host permissions default off; enabling Shell grants execution as the host process user.
Invitation secrets encrypt the session; this version has no persistent device identity or forward secrecy, and an untrusted relay requires an independently trusted HTTPS Web client origin.
Desktop behavior needs physical-device validation and the ordered connection has no low-latency guarantee; the Cloudflare relay defaults to a 64 MiB cumulative per-session forwarding quota.
Binaries are unsigned and macOS builds are not notarized; SHA256SUMS checks download integrity.

See CAPABILITIES.md and docs/verification.md in the source tree for the recorded build, automated test and runtime evidence.
