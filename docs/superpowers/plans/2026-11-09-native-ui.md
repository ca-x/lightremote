# Native Controller UI Implementation Plan

> Execute inline with the executing-plans workflow; no parallel workers needed.

**Goal:** Replace the native controller's all-tools form with a permission-aware session workspace.
**Architecture:** Preserve the Rust client/network worker and native surface; compose NSH base controls through app-owned tokens and styled controls. Keep workspace drafts mounted and release remote input on navigation.
**Tech Stack:** Rust, pinned NSH 0.4.0 revision, Cargo, NSH Headless.
**Spec:** `docs/native-ui.md`.

## Global Constraints

Permissions fail closed. Do not change TMP, relay behavior, host defaults or dependency revisions. No source copying, secret persistence or automatic request replay. Preserve no-overwrite file commits.

## Review Focus

- Disconnected, connecting and permission-denied actions must not send work.
- Tabs must support keyboard navigation and retain local drafts.
- Hidden desktop surfaces must not continue forwarding armed input.
- Display queries must not replace capability state.
- Dark/reduced-motion and compact views must preserve readable states.
